# 生詞遊戲（曼米中文）

配對 Match、Blast、快問快答 Quiz、聽音排序 Listen & Order 四種生詞遊戲：老師投影試玩、作業／自主練習連結、全班即時比賽（像 Kahoot）。

## 在平台裡

課堂活動 → 選班級 → **配對 Match**、**Blast**、**快問快答 Quiz** 或 **聽音排序 Listen & Order**（課次頁的「活動」分頁、上課中的「活動選單」也有）。

- **出題範圍**：勾選課次、每一課抽幾成（「從最近一課往前」一鍵套用 100%、80%、60%、40%、20%，可以再改）；固定（照課本順序）或隨機；一局最多幾個生詞（超過時每一課照比例減少）。
- **翻譯語言**：英文、泰文用生詞庫原本的；日文、越南文、菲律賓文等第一次用到時自動翻譯，老師可以在「檢查／修改翻譯」改，存在老師帳號（`teacherPlatform/{老師}/gameTr/{語言}/{詞}`），不會改到教材。拼音也可以在這裡修正（數字標調 ni3 hao3 會自動轉成 nǐ hǎo）。
- **讀音**：注音（預設）或拼音。注音用生詞庫的「注音」欄，沒有的從拼音自動轉；選注音時遊戲裡所有拼音的地方都換成注音（Blast 的打拼音模式只在拼音時出現）。
- **配對**：比速度（全部配完，記時間和錯誤）或限時（預設 60 秒，一批配完自動換下一批）；詞語 ↔ 拼音／翻譯／拼音＋翻譯／圖片；一次 4～8 組。
- **Blast**：看詞語選拼音／選翻譯／選圖片、看拼音／翻譯／圖片選詞語，或看詞語打拼音；生命、速度（1～5）、時間可以設。
- **復活挑戰**（即時多人的 Blast，預設開啟）：命用完時連續答對自己答錯的詞（3 題起，每復活一次多 1 題）就帶 1 條命回到遊戲，挑戰本身不加分；沒有設時間時即時遊戲用 90 秒。學生自己練習時命用完就結束。
- **快問快答 Quiz**（`quiz.js`）：像 Kahoot，一題一題出，四個顏色的答案選一個。題型：看詞語選拼音／翻譯／圖片、看拼音／翻譯／圖片選詞語、**聽聲音選詞語／翻譯**、綜合（每題不一樣，缺拼音／翻譯／圖片的詞自動跳過）；題數 5～20、每題 10～30 秒。答對 100 分＋速度加分（最多 50 分），答錯扣 20 分，沒作答不扣分、連對有 🔥 提示。**即時多人時全班照同一個開始時間排程**（每題「作答 N 秒＋公布 3.5 秒」），所以每個人自動在同一秒進到同一題，老師不用一題一題按；中途加入或重新整理的學生從目前這題接上，沒看到的題不計分，答過的題不會重複計分。老師的畫面會同步顯示題目、倒數和正確答案（可以直接投影），但老師不作答。作業連結／自己練習：答完就公布答案，過 2 秒自己進下一題。
- **聽音排序 Listen & Order**（`order.js`）：念出一串詞語，學生把卡片拖進格子，排成聽到的順序（手機上點一下卡片會放進下一個空格，點格子裡的卡片放回去；格子之間可以拖曳互換）。第一輪的詞數可以自己設（2～12 個；程度好的班可以從 5、6 個開始），之後**每輪多一個詞**直到上限（4～30 個，或「用完所有詞」；設定頁會顯示這次會從幾個詞排到幾個詞、共幾輪、整局大約幾分鐘）。詞太多時（超過 10 個）卡片會自動縮小。要排到很多個詞，記得在「出題範圍」多勾幾課、「一局最多」調高；詞表是同一份往後加，但**念的順序每輪重新打亂**，不能靠背上一輪。**怎麼聽**有兩種：
    - **自由**（預設）：每輪一開始就念，邊聽邊排，可以按「聽」重聽（每輪 1～3 次，自動念的那次算一次）。
    - **考記憶**：全班**先一起聽完一次音檔（不能重聽），整段念完才開始作答**；聽的時候卡片會先出現但不能動。音檔多長是由詞的字數固定算出來的，所以全班同一秒開始作答；聽到一半才進來的人，這輪不計分。
  - **語速**慢／一般／快（預設）／更快／極快（詞跟詞之間只停 0.2／0.15／0.1 秒）。更快、極快需要語音伺服器的新版（`tts-server/main.py`，上限從 1.2 調到 1.6）；伺服器還是舊版時，網頁會自動偵測（`/health` 的 `maxRate`），念到 1.2 之後用加快播放補（聲音會稍微變尖一點），部署新版後就不會變尖；作答時間依詞數調整（緊湊／一般／寬鬆）；卡片可以顯示詞語＋讀音、只有詞語或只有讀音。
  - **生存模式**：預設 2 條命，答錯扣 1 條。命用完＝被淘汰，但**不會沒事做**：進入「旁觀練習」——照樣聽、照樣排、照樣批改，只是不計分；開啟「復活」（預設開）時，**連續答對 2 輪就復活**（回到遊戲、有 1 條命）。最後比分數（淘汰的人少拿了後面幾輪的分，所以撐越久分數越高）。老師的排行榜會顯示每個人「最長排對幾個詞」、剩幾條命或「旁觀練習中」。學生自己練習（作業連結）時命用完就結束。
  - **累積模式**：沒有淘汰，打滿所有輪，比總分。
  - 計分：全對＝100 分＋每多一個詞 +20 分＋速度加分（最多 50 分）；排錯的輪，每個放對位置的詞也有一點分數（最多 50 分），但仍算答錯。
  - 即時多人跟快問快答一樣由共用時鐘排程，老師的畫面同步顯示輪數、倒數和正確順序（投影用，不顯示卡片）。
  - **發音**：用曼米語音伺服器的自然語音（預設「曉臻」（曉珍），跟平台生詞發音同一個；也可以選曉雨、雲哲），先在等待室把這局的詞下載好，用 WebAudio 播放——聲音自然、速度由我們控制，不受裝置好壞影響。伺服器連不上（或詞還沒載好）才改用裝置內建的中文語音，優先順序：曉臻（曉珍）> 其他台灣語音 > 任何中文語音；都沒有的話學生會看到提示。伺服器網址跟平台共用（`tts-config.js`、或 `tts.html` 的「⚙ 語音伺服器」）；免費主機閒置會休眠，等待室一開就會先叫醒它。iPad／iPhone 要先點過畫面才能自動播放，所以加入房間時點一下就會解鎖。
- **主題（背景）**：兩個遊戲都可以選：宇宙、天空氣球、海底泡泡、水果（配對另外有米色）。選主題時背景音樂會換成搭配的曲子；學生自己練習時可以換主題。
- **背景音樂**：快樂、冒險、放鬆、太空、海洋（`music.js` 即時合成，不用音檔）；限時最後 10 秒會加快。遊戲一開始音樂和音效就是開的（即時多人時學生的裝置也會播放，老師可以在設定關掉）；玩家可以用遊戲畫面上的「音樂 開／關」「音效 開／關」自己關，只在這次有效，下次打開又是開的。iPad／iPhone 等要先點一下畫面才能出聲：加入、開始或點任何卡片時就會順便解鎖；上課中自動加入、還沒點過畫面的學生，等待室會出現「點一下這裡打開聲音」，遊戲開始時上方會提示「點一下畫面就有聲音」。
- **圖片**：老師上傳的圖片（教材的「圖片」欄）優先，沒有就用「Emoji／圖示」。可以在生詞卡上直接「上傳圖片」，或在遊戲的「檢查／修改翻譯、拼音、圖片」上傳；上傳的圖片存在 `teacherMedia/{老師}/`，網址存進教材，生詞卡、配對、Blast 都用同一張。只在遊戲裡改的 Emoji 存在 `gameTr/_img`，不會改到教材。
- **給學生看的文字都有英文**：按鈕、提示、結果、排行榜、等待室都是「中文＋English」，程度還不夠的學生也知道怎麼玩。
- **作業／自主練習連結**：`games/?t={老師}&set={id}`，學生填名字就能玩、可重玩；成績在「查看作業連結的成績」，可匯出 CSV。
- **即時多人**：房間代碼、連結、QR code；學生只填名字（重複的名字自動加編號）；等待室可以移出學生、分組；全班同步倒數、即時排行（個人、組別）、最後排行、CSV、再玩一局。遊戲中排行榜在畫面上方一條橫列。等待室和最後排行可以按「換遊戲／改設定」：學生留在房間等，老師改好按「套用到房間」，不用重新掃 QR code。學生重新整理會回到原本的身分和分數；老師重新整理，設定頁上方有「回到房間」。上課中（開始上課）開房間，學生的畫面會自動加入，不用輸入代碼和名字。
- **分組**：隨機（分成幾組／每組幾人，可重抽，鎖定的學生不動）或自己分（點學生再點組別、可拖曳），可以改組名；每個班存一份（`teacherPlatform/{老師}/gameGroups/{班級}`），學生加入即時遊戲時名字一樣的會自動進到分好的組。
- **計分**：答對 100 分＋速度加分（最多 50 分），答錯扣 20 分。組別分數預設是「有效成員」的平均（開始時在房間而且有作答；中途斷線的也算），可以改成總分；同分比平均正確率，再比平均反應時間。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 頁面、Firebase 連線（學生匿名登入） |

## 加新的主題

在 `themes.js` 的 `MG.THEMES` 加一筆，並把名字加進 `MG.THEME_ORDER`（配對也會自動出現在 `MG.MATCH_THEMES`）：

```js
snow: {
  name: "雪花", music: "relax", dir: 1,  // 搭配的背景音樂；1 往下掉，-1 往上飄
  bg: "linear-gradient(#DDEBF7, #fff)",  // 背景
  deco: function(){ return '<svg …>…</svg>'; },   // 背景裝飾（可省略）
  shape: function(i){ return '<svg class="shape" viewBox="0 0 150 110">…</svg>'; },  // 物件圖形，i 用來換顏色
  label: { lc: "#2B2320", ls: "none" },  // 字的顏色、陰影（可加 ly、lh 調整字的位置）
  spark: ["#5B9BD5", "#fff"]             // 爆開的顏色
}
```

## 即時遊戲的資料與用量

- 房間：`liveGames/{代碼}`。資料庫規則還沒更新時，自動改用 `rooms/mmg_{代碼}`（現在的規則已經允許），所以不用等規則也能玩。
- 規則（`firebase-rules.json`、`firebase-rules-v2.json` 已經加好 `liveGames`）：只有開房間的老師能改房間設定、開始／結束、移出學生、刪除房間；學生只能寫自己的 `players/{uid}`、`scores/{uid}`，被移出後就不能再寫。過期（6 小時）的房間任何人都能刪。
- 清理：關閉房間時刪除；老師下次開房間時，會順便刪掉自己 6 小時以前的房間。
- 省流量：學生的分數最多每 1.5 秒寫一次；學生只聽老師每 2.5 秒整理一次的排行榜（前 5 名＋自己的名次，不到 1 KB），不聽全部人的分數。15 人玩 5 分鐘，下載量大約 5～10 MB（免費方案每月 10 GB，存放 1 GB）。
