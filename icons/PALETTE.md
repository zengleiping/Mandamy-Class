# 曼米中文 配色

顏色是從新圖示（icons/ui、icons/act-*）本身抽出來的，網站的配色跟圖示一致。
各頁的 `:root` 變數是來源；`tools/icons/recolor.py` 記錄了「舊色碼 → 新色碼」的對照，可以重複執行。

| 角色 | 變數 | 色碼 | 說明 |
| --- | --- | --- | --- |
| 頁面底色 | `--paper` | `#F7F0E1` | 帶奶油的米色（圖示的內裡色） |
| 面板底色 | `--surface` | `#FFFCF6` | 暖白 |
| 次要面板 | `--surface-2` | `#EFE3CC` | 深一點的奶油 |
| 文字 | `--ink` | `#352C27` | 暖灰褐，跟圖示外框同一個色系（外框 `#49423D`） |
| 次要文字 | `--ink-soft` | `#66594F` | 在米色上對比 6.0:1 |
| 外框線 | `--line` | `rgba(73,66,61,.22)` | 圖示外框色的淡版 |
| 主色 | `--seal` | `#B25F38` | 陶土橘；白字對比 4.6:1（舊的蜜桃橘只有 2.7:1） |
| 主色深 | `--seal-d` | `#8F4524` | 懸停、小字、按鈕底邊 |
| 主色淡底 | `--seal-soft` | `#F6E2D2` | |
| 副色 | `--bamboo` | `#647E58` | 橄欖綠；白字對比 4.5:1 |
| 副色深／淡底 | | `#4F6844` ／ `#E5EBDA` | 成功、完成 |
| 資訊 | `--slate` | `#5A7590` | 灰藍；連結、資訊 |
| 警告 | `--mustard` | `#DCAC62` | 赭黃；提醒、獎勵 |
| 錯誤 | `--brick` | `#A63B42` | 磚紅 |

共用的外觀細節（選取色、焦點框、主要按鈕底邊）在 `icons/mm-theme.css`。
插畫類（寵物、遊戲背景主題、打貓咪的貓）的顏色沒有動，等背景與角色另外決定。
