# Firebase 搬家指南（額度用完時，換到另一個 Firebase 專案）

## 什麼時候需要搬家

- 每個 Firebase 專案**每月有自己的免費額度**（資料庫下載 10 GB），每月 1 日重置。
- 搬家**不是每個月固定做一次**，而是「這個專案的額度快用完時」才換到另一個專案（準備 A、B 兩個專案輪流）。
- 例如：A 專案用到月中快滿 → 搬到 B → B 用到快滿或月底 → 再搬回 A（A 已經重置）。大約一個月 1～2 次。
- 先把流量降下來（圖片縮小、學生端快取），搬家才不會太頻繁。

## 先知道的限制

- 搬家時，**從匯出到切換完成之間的修改會遺失**，請選一個沒有課、沒有人在用的時段（例如週末晚上）。
- 老師搬家後要**重新登入一次**（用原本的帳號密碼，系統會自動重新認領）。
- 學生連結不變，但學生**要重新整理頁面**。
- 學生如果有綁 Google 登入，搬家後要重新綁一次。
- 上課當下的暫存（課堂房間、遊戲房間）不會搬，搬完要重新開房間。
- 整個過程約 1～2 小時，每次都要你親自操作 Firebase 後台。

## 一次性準備：建立新專案（B 專案）

1. 用 Google 帳號開 <https://console.firebase.google.com> → 新增專案，名稱例如 `mandamy-b`。**不要啟用 Blaze**，維持 Spark（免費）。
2. 專案設定（齒輪）→ 一般 → 你的應用程式 → 新增網頁應用程式（`</>`），不用勾 Hosting。建好會看到一組 `firebaseConfig`，**整段複製下來**。
3. 建立 Realtime Database：Build → Realtime Database → 建立資料庫。位置選「新加坡（asia-southeast1）」，規則先選「測試模式」（搬完再換）。
4. 啟用登入方式：Build → Authentication → 開始使用 → Sign-in method，打開三個：
   - **電子郵件／密碼**（只開第一個開關，不要開「電子郵件連結」）
   - **匿名**
   - **Google**（要填專案的支援電子郵件）
5. Authentication → Settings → 已授權的網域，新增 `zengleiping.github.io`。

## 搬家日的步驟（照順序）

1. **通知大家**這段時間不要用平台。
2. **匯出舊專案**：舊專案 → Realtime Database → 資料，在最上層根節點（資料庫網址那一列）按 ⋮ → **匯出 JSON**，檔案會下載到電腦。
   - 如果舊專案顯示「已超過用量限制」，要等下個月 1 日重置後才讀得到。
3. **整理檔案**（我來做，或自己用 Python）：
   - 把匯出的 JSON 傳給我，我用 `tools/migrate/prepare_import.py` 整理，產生 `全部一次匯入.json`。
   - 整理時會：只留要搬的資料、拿掉舊的登入身分（老師才能在新專案重新認領）、不搬上課當下的暫存。
4. **匯入新專案**：新專案 → Realtime Database → 資料，在最上層根節點按 ⋮ → **匯入 JSON**，選 `全部一次匯入.json`。
   - 匯入上限約 256 MB；如果檔案太大，我會幫你分段。
5. **貼上規則**：新專案 → Realtime Database → 規則，把專案裡的 `firebase-rules-v2.json` 整份複製貼上 → 發布。
6. **把新專案的 `firebaseConfig` 給我**，我會更新 `firebase-config.js`（全站只有這一個檔案）並合併，GitHub Pages 約 1～2 分鐘後生效。
7. **驗證**（我生效後告訴你）：
   - 用管理員帳號登入平台，確認班級、教材都在。
   - 開一堂測試課堂，用手機當學生進去。
   - 請另一位老師登入一次。
8. **舊專案先不要刪**，保留當備份，確認一週沒問題再處理。

## 搬回舊專案（下次）

和上面一樣：從目前專案匯出 → 整理 → 匯入舊專案（先把舊專案資料庫根節點清空，避免新舊資料混在一起）→ 規則確認還在 → 請我改 `firebase-config.js`。

## 出問題怎麼辦

- 老師登入顯示「帳號或密碼錯誤」或衝突：告訴我，通常是舊的登入身分沒清乾淨，我再處理。
- 資料不見：舊專案沒有被動過，請我把 `firebase-config.js` 改回舊專案即可還原（這就是舊專案要保留的原因）。
- 學生看不到資料：確認新專案規則已發布、授權網域有加 `zengleiping.github.io`。
