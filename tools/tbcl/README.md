# TBCL 等級檢核與語料庫工具（曼米中文 · 備課工具）

入口：平台課次頁「TBCL 等級檢核」，或直接開 `tools/tbcl/`。

0. **✨ 一鍵改寫**（預設首頁）：貼上文章、選等級（1–7），按一個鈕。步驟：詞庫換詞（只採用可靠的換法：我的換法、精選成語說法、只有一個意思的辭典說法）→ 請 AI 把整篇改寫成該等級（分段，每段用詞表檢核，超綱就帶著難詞清單再改，最多 3 輪）→ 顯示超綱比例前後與改寫結果。還超綱的詞用「點一下」換掉或標成專有名詞。其他工具收在右上角「進階工具」。
   - **AI 預設用 [Puter](https://docs.puter.com/)（不需要金鑰）**：第一次按下按鈕會請使用者登入免費的 Puter 帳號，AI 用量由使用者自己的 Puter 帳號負擔，不會用到網站擁有者的費用（Puter 的「使用者付費」模式；免費額度與條款依 Puter 為準）。也可在「進階工具 → AI 設定」改用自己的 Gemini／Claude 金鑰，或選「不用 AI」（只用詞庫）。
   - 不想登入也可以：結果頁的「複製指令到 ChatGPT／Gemini／Claude 網頁」會附上該等級的常用詞和難詞清單，把網頁回答貼回來再檢核。
1. **等級檢核**（含「逐句修改建議」：超綱詞可換詞——先查近義詞工具書與教育部近義詞，沒有再問 AI，AI 的建議一律用詞表驗證；整句改不動時可請 AI 換句話說，改完自動再檢核、最多 3 輪；可套用與復原，AI 呼叫會記進人機協作紀錄）：貼上文字、選目標等級（1–7）與標準（教材 15%／試題 10%），標出超綱詞與詞表沒有的詞；專有名詞點一下排除；可選擇「* 級詞算在該級內」；可複製結果、列印成 PDF，也可以一鍵把文字送到國教院「教材編輯輔助系統」在新視窗看官方結果。
2. **AI 依等級生成**：Gemini／Claude 產生內容後自動檢核，超綱太多會帶著超綱詞清單請 AI 改寫（最多 4 輪）；每次呼叫記入「人機協作紀錄」，可複製成競賽附件 3 的表格。
3. **教材等級盤點**：全部生詞標 TBCL 等級、各課課文超綱比例、詞表沒有的生詞、教材語法點對應 TBCL 語法點表（自動比對名稱，僅供參考）、CSV 匯出。
4. **語料庫例句**：在教材課文與例句裡查詞（KWIC＋前後搭配），並顯示 COCT 通用詞頻。
5. **語法點表**：官方語法點表可依等級、關鍵字查詢。

資料與重新產生方式見 `data/README.md`。檢核是用詞表做雙向最大匹配斷詞後比對，結果會跟官方「教材編輯輔助系統」略有出入，**正式送件前請仍以官方系統檢核並附上結果**。

## 等級標準選單

課次頁「生詞・語法・課文」旁的「等級標準」可選 TOCFL、TBCL、HSK 3.0（2021／2026）或不顯示。選擇存在這個瀏覽器（`mm_std`），教材頁的生詞卡與語法卡、生詞表製作工具會跟著切換（程式在根目錄 `std.js`）。語法卡的 TBCL 等級是用名稱自動比對，僅供參考。

## 詞表沒有的詞組（成語、新詞）

詞表沒有的成語或新詞（例如「風生水起」）斷詞時會被切成單字，單字各自都在詞表裡，超綱比例會被低估。工具會：
1. 用補充字典（`data/lexicon.txt`，教育部詞條中不在 TBCL 的 3 字以上詞）把已知的成語和長詞當成一個詞，標「詞表沒有」。
2. 連續好幾個單字、看起來像詞組的，列在結果最上方的「可能有詞表沒有的詞組」，請老師確認範圍後按「確認為一個詞」。確認過的詞存在瀏覽器，下次檢核自動沿用，也可以指定它是第幾級。

## 換詞建議的來源（不用金鑰）

「逐句修改建議」的換詞按鈕來自離線整理好的 `data/replacements.json`，網頁只是讀資料，不連網、不用金鑰。每個候選會標來源：
- **辭典同義**：重編國語辭典、近義詞工具書、教育部近義詞明列的同義詞（最可靠）。
- **辭典說法**：用辭典釋義改寫成白話（人才濟濟→「人才眾多」、犯錯→「做錯事」、水洩不通→「擁擠不堪」）。釋義裡還有超綱詞時，會用換詞表再換一次（標「再簡化」，例如目標 4 級時「人才許多」）；最後一律用詞表確認改完沒有超綱詞才列出。釋義可能是詞的另一個意思，套用前請看整句。
- **釋義用語**：來源詞的辭典釋義裡直接用到的較低等級詞（例如「重視：認為重要而加以**注意**」），已排除反義與否定用法。
- **語義相近**：辭典釋義的詞義向量非常接近（相似度 ≥ 0.82）。

這份表只比對詞義、不看整個句子，換進句子可能不通順；有些詞（如「經濟」「話題」）找不到合適的低等級詞，就不會有候選，這是正常的。整句改寫仍需要 AI（金鑰）或人工。

候選一律依「目標等級」過濾：換詞按鈕只列等級不超過目標的詞；沒有符合的時候，會顯示辭典裡最接近但仍高於目標等級的詞，讓老師知道是「沒找到」還是「找到了但太難」。

## ⑥ 整篇文章

貼上整篇文章（例如從網路複製的），選學生等級：
1. 列出所有超綱詞和詞表沒有的詞（專有名詞用「① 等級檢核」點選排除）。
2. 每個詞給建議的簡單說法，來源依序是：**精選說法**（人工撰寫並驗證）→ 辭典同義／說法 → 釋義用語／語義相近；可選「換成」「加註（詞（說明））」「保持原樣」或自己輸入。
3. 「全部採用第一個建議」或逐一選擇後「套用」，產生改寫後的文章，換過的地方標色，並顯示超綱比例的前後變化。可拿去「① 等級檢核」再檢核。
換進句子的說法不一定通順，請老師直接修改。

### 換進去怎麼讓它通順

- **依位置選形式**：精選成語每個有四種形式——一般、接「的」、接「地」、放在「得」後面（`build/curated-roles.tsv`）。工具看成語前後的字（的、地、得）自動挑對的那一個：「如痴如醉**地**工作」→「非常開心地工作」、「嚇**得**目瞪口呆」→「嚇得說不出話」、「落英繽紛**的**季節」→「花一片一片掉下來的季節」。
- **自動接合**：沒有該位置的形式時，把說法截成第一個短句再接上；避免「很很」「累得很累」這類重複；仍可能不通順的位置會列在「請檢查這幾處」。
- **請 AI 順稿**（選用，需要金鑰）：只改換過的句子，改完用詞表確認沒有更超綱，老師勾選後套用；評審展示不依賴它。
- **我的換法**：自訂換法勾「記住」，存在瀏覽器，下次同一個詞排在最前面；可複製成文字備份、在別台電腦匯入。
