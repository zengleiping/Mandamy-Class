# 近義詞工具書（曼米中文 · 學習工具）

《1700對近義詞語用法對比》全書 1718 組，加上另外整理的補充詞組。每組都有詞義說明、詞語搭配表、用法對比（附英文）、例句練習，可以用拼音或注音查詢；台灣繁體、台灣讀音。

## 在平台裡

- 老師／助教：上方選單「近義詞」。
- 學生：班級首頁「📖 近義詞工具書」。
- 以全螢幕視窗打開，按「關閉 ✕」回到原本的頁面（不會跳離目前的頁面）。

## 螢光筆與筆記

在詞組頁面選取文字，可以畫螢光筆（4 色）、加筆記；點已經畫的地方可以改顏色、改筆記或刪除。每組下方的「我的筆記」整理這一組的全部標記，列表的「✎ 我的標記」只顯示有標記的詞組。

筆記由 `app.html` 存到登入者自己的帳號（不存在瀏覽器裡，共用 iPad 也不會看到別人的）：

| 誰 | 存在哪裡 |
| --- | --- |
| 老師／助教 | `teacherPlatform/{老師}/synNotes/{帳號}/{詞組 id}` |
| 學生 | `teacherPlatform/{老師}/hwFiles/{班級}/_synNotes/{學生}/{詞組 id}` |

每個詞組存成一段 JSON 文字。這兩個位置在 `firebase-rules.json` 和 `firebase-rules-v2.json` 都已允許寫入，**不必改 Firebase 規則**。（學生的筆記借用作業附檔 `hwFiles` 底下的 `_synNotes`，平台只會用作業 id 讀 `hwFiles`，不會把它當成作業。）

## 和平台之間的訊息

工具網址要帶 `?embed=1`，而且要跟平台同一個網域，才會用平台存筆記：

- 工具 → 平台：`{ mmSyn: "ready" }`、`{ mmSyn: "save", entryId, items }`
- 平台 → 工具：`{ mmSyn: "notes", signedIn, who, notes: { 詞組id: items } }`、`{ mmSyn: "saved" }`、`{ mmSyn: "saveError" }`

直接打開 `tools/synonyms/`（沒有 `embed=1`）時，筆記存在這台裝置的瀏覽器裡。

楊寄洲、賈永芬編著《1700對近義詞語用法對比》（北京語言大學出版社）。內容依原書轉錄、轉成台灣繁體，英文翻譯為另行撰寫。「補充」分類的詞組不在原書中，為另行整理的內容。
